# Kiln Store

New app (not a fork), GPL-3.0-or-later. Python 3 + GTK4 + libadwaita. Backends: apt (`apt-cache`, `dpkg-query`; install/remove
through `pkexec apt-get`) and Flatpak CLI (user installation, Flathub remote added on first install). Themed by
`../theme/adw.css.in` (generated into `data/kiln-*.css`).
