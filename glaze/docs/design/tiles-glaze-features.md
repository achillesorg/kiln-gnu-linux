# TilesDE and Glaze: new-feature plan

Status: proposal, 2026-11-19. Nothing here is implemented. Planning only.

Inputs read: `tilesde/HANDOFF.md`, `tilesde/docs/tiles-spec.md`, `tilesde/docs/mobile-DECISIONS.md`, `tilesde/docs/mobile-needs-from-fede.md`, `tilesde/shell/qml/apps/README.md` and `index.js`, `tilesde/shell/src/Services.h`, `glaze/GLAZE.md`, `glaze/AGENTS.md`, `glaze/docs/overhaul-plan.md`, `glaze/docs/visual-spec.md` (headings), `glaze/docs/design/{convergence,tool-suite,windows-switcher,KILN-PLAN}.md` (headings plus the relevant sections), `glaze/PROJECT_STATUS.md` (headings plus working-feature rows), `glaze/docs/decisions.md` (grep). Facts not re-verified in code are marked (verify).

Tags: **NEW** = not in any existing doc or code. **EXTENDS** = builds on an item that is already planned or partly built; the "Builds on" column says which. Effort: S under 2 days, M about 1 week, L 2 to 4 weeks. Priority: P0 blocks other work, P1 core to a daily phone or desktop, P2 mature, P3 optional.

### A1. Platform services behind the mocks

| ID | Feature | Tag | Description and UX | Implementation | Eff | Pri |
