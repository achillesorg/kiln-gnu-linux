# Glaze / Kiln GNU/Linux assets

Wallpapers, ink icons, the Kiln brand kit and the boot splash. Everything here
is original, generated by stdlib-only Python scripts, and licensed
**MIT OR Apache-2.0** like the rest of the repo. No third-party images, icon
packs or fonts are bundled. Nothing comes from Anthropic, Microsoft or any
other party's artwork.

Style source of truth: `docs/decisions.md` (flat cut paper, hard edges, small
tone-on-tone offsets, thin strokes, no blur, no gradients, no heavy black shadows).

## 1. Wallpapers (`assets/wallpapers/`)

| Set id | Title | Schemes | Notes |
|---|---|---|---|
| `paper-hills` | Paper Hills | light, dark | **Original v1, unchanged, still the default** (`DEFAULT_WALLPAPER_SET`). SVG with soft shadows. |
| `terracotta-waves` | Terracotta Waves | light, dark | Original v1, unchanged. |
| `hills-hard-edge` | Hills (hard edge) | light, dark | Same hills, sun and clouds as Paper Hills; blurred shadows replaced by hard flat offsets. |
| `kiln` | Kiln | light, dark | Terracotta field, stacked cream sheets, ink sun, tone-on-tone kiln arch. |
| `draft` | Draft | light, dark | Cream field, paper hills with ink contour lines, clay sun. |
| `margin` | Margin | light, dark | Minimal: hand-ruled terracotta margin, one paper arch. |
| `night-paper` | Night Paper | dark only | Charcoal, cream sheets, paper moon, terracotta disc. Light falls back to it (resolver rule). |
| `classic-teal` | Classic Teal | light, dark | Flat heritage teal, faint arch, terracotta dot, light grain. |

Every dark variant contains terracotta.

**Files.** For each v2 set:
`<set>/src/<set>-<scheme>-<orientation>-<W>x<H>.svg` (source) and
`<set>/<set>-<scheme>-<orientation>-<W>x<H>.png` (render with grain baked in) for
1280x800, 1920x1080, 2560x1440 (landscape) and 1080x2340 (portrait).
Contact sheet: `assets/wallpapers/contact-sheet.png`.

**Manifest.** `manifest.toml` stays schema 1 and is parsed by the existing
resolver without changes. This was checked by building a scratch binary
against `glaze-common` that loads the manifest and resolves every set x scheme x
orientation to an existing file. For v2 sets, `file` points at the
1920x1080 / 1080x2340 PNG. Extra keys `seed`, `source` and `renders` are
ignored by serde and record reproducibility plus the other sizes. The legacy
entries are written first, verbatim.

**Regenerate.**

```sh
python3 scripts/gen-wallpapers.py                 # v2 sets, manifest, contact sheet (needs rsvg-convert)
python3 scripts/gen-wallpapers.py --set kiln --seed 3   # try another composition
python3 scripts/gen-wallpapers-legacy.py --out /tmp/wp  # reproduce the v1 SVGs byte-for-byte
python3 assets/wallpapers/tools/lint-svg.py       # fails on <filter>, fe*, blur, gradient
```

The v1 SVGs are never rewritten by `gen-wallpapers.py`. A backup with
SHA-256 sums is in `$HOME/fedeos/brand/wallpapers-original/`. They contain
a blur filter, so the lint skips them by name (`--legacy` includes them and fails, as expected).

**Grain.** A 256 px tileable tile (speckle, soft blotches and faint fibres) is
generated in the script. It is warm-white/ink at alpha 11/255 or less, about 2-4 %
luminance. It is composited only in the PNG step, by wrapping the source in a
throwaway SVG. Use `--no-grain` for clean PNGs.

### Needs from agent A (do not change without the user)

1. `scripts/install-session.sh` copies only top-level files of
   `assets/wallpapers/*`. The v2 sets live in subdirectories (`kiln/…`), so
   they would not be installed. Copy the tree recursively (PNGs are enough;
   `src/` is optional).
2. To make a v2 set the default, change `DEFAULT_WALLPAPER_SET` in
   `crates/glaze-common/src/config.rs` (for example to `"kiln"`). It is left as
   `paper-hills` per the user.
3. Optional future schema: per-size picking (use `renders` to choose the
   closest size to the output). The current resolver cover-crops the 1920x1080
   PNG, which is fine.

## 2. Ink icons (`assets/icons/ink/`)

41 shell glyphs on a 24 px grid: start (Kiln arches), search, apps, folder,
terminal, browser, settings, power, restart, logout, lock, sleep,
network-wifi / -wifi-weak / -wired / -off, volume-mute / -low / -medium / -high,
battery-empty / -low / -medium / -full / -charging, bell, bell-dot,
window-close / -minimise / -maximise / -restore, layout-float / layout-tile,
pin / unpin, chevron-up / -down / -left / -right, clock, calendar.

| Variant dir | Stroke | Use |
|---|---|---|
| `stroke-1.5/` | 1.5 px | default |
| `stroke-1.25/` | 1.25 px | hairline UI (taskbar mockup weight) |
| `duo-1.5/` | 1.5 px | plus flat fill at 16 % of currentColor |

Rules: `currentColor` only, round caps and joins, absolute path commands,
every coordinate on the 0.25 px grid and inside 1..23.

**Fill token.** Shapes with `class="glaze-fill"` are the flat paper area of a
glyph. They are present but transparent in the stroke variants, so CSS can tint them.
`class="glaze-badge"` (the bell dot) can take the terracotta accent.

```sh
python3 assets/icons/ink/gen_icons.py     # write all variants
python3 assets/icons/ink/check_icons.py   # validate (currentColor, grid, caps, bounds)
python3 assets/icons/ink/make_sheet.py    # contact-sheet.png at 16/24/32/48 px, light + dark
```

**Caveat for agent A.** These are stroke icons. GTK's built-in *symbolic*
recolouring forces `fill` on every shape and breaks stroke outlines. Load them
as normal SVGs with `color` set, for example by rendering with librsvg and a
`color:` stylesheet. Another option is a small loader that substitutes `currentColor`. The existing
`assets/icons/glaze-*-symbolic.svg` files were not touched.

## 3. Kiln brand kit (`$HOME/fedeos/brand/kiln/`)

Generators: `brand/gen_kiln_logo.py` (symbols, lockups, splash stills) and
`brand/gen_kiln_icons.py` (favicon, app and web icons). Before them, run the
logo-design skill's `export_variants.py … --web-icons --out-dir web` for the
one-colour SVG variants.

| File | Use |
|---|---|
| `kiln-symbol.svg`, `-on-dark`, `-mono-black`, `-mono-white` | master symbol (32 px and up) |
| `kiln-symbol-small*.svg` | **16 px cut**, pixel-snapped on a 16-unit grid (use at 16 and 32 px) |
| `kiln-lockup*.svg` | symbol + "kiln" |
| `kiln-lockup-full*.svg` | symbol + "kiln" + "GNU/Linux", all paths, no live text |
| `kiln-lockup-stacked*.svg` | stacked full name, for narrow spaces |
| `web/` | `favicon.svg` (dark-mode aware), `favicon.ico`, 16/32/48 PNGs, apple-touch, 192/512, maskable, `site.webmanifest`, `head-snippet.html` |
| `app-icon/kiln-<n>.png` | 16-512 px app icon for a hicolor theme (16 uses the small cut) |
| `kiln-boot-animated-{dark,light}.svg` | SMIL preview of the boot motion |
| `review/preview.html`, `review/preview.png` | logo-design test sheet |

**Audit results** (`svg_audit.py`). The issues found were fixed:
- the lockup's right margin was 0 and is now 28, matching the left;
- the k arm was 1-1.5 degrees off and is now exactly 45 degrees;
- the full lockup's N and slash diagonals were snapped to 60 and 75 degrees.

Scores are now 99-100, and 98 for the extra-wide full lockup, which carries an
advisory to also ship the stacked lockup (done).

At 16 px the master's 18-unit counter smeared, so a small cut was added.

**Accepted findings:**
- terracotta on cream is 3.0:1. This is fine for a logo; never set small terracotta text on cream;
- vertical margins of 20/28 are optical (arch mass sits low);
- the audit's "white knockout" warning on `-on-dark` is a false positive (the cream inner arch is a separate shape, not a hole).

**Clear space.** At least the outer arch's band width on every side, which is
32/256 of the symbol height (about 1/8). For lockups, measure from the symbol.

**Minimum sizes.**

| Asset | Minimum |
|---|---|
| master symbol | 24 px |
| small cut | 16 px |
| `kiln-lockup` | 20 px tall |
| full lockup | 32 px tall ("GNU/Linux" stroke is 12/256) |
| stacked lockup | 64 px tall |

**One-colour use.**
- Use `-mono-black` / `-mono-white` (both arches the same colour; the
  gap between them carries the shape).
- On a terracotta background, use the white or ink mono version.
- Never put the two-tone symbol on terracotta: the outer arch vanishes.
- On dark, use the `-on-dark` files: the ink inner arch disappears on charcoal.
- Do not recolour single arches, add effects, outline, rotate or stretch.

**Fonts.** None are bundled. OFL candidates (package or bundle later with
licence):
- UI: **Inter** (Debian `fonts-inter`);
- display serif for the clock and headings: **Source Serif 4**, **Fraunces**, **Newsreader**;
- alternatives: **Literata**, **IBM Plex Sans / Serif**, **Atkinson Hyperlegible**;
- fallback: Noto Sans / Noto Serif.

The wordmarks are custom geometric paths and need no font.

## 4. Boot splash (`packaging/kilnlinux/plymouth/`)

Generator: `gen_plymouth.py`. All three forms come from one timeline:
- 0-0.7 s: the outer arch slides up 36 px and fades in;
- 0.22-0.95 s: the inner arch slides up 56 px, with ease-out-back (small settle, no steps);
- after that, the counter glows like an ember (2.8 s sine pulse) and a 3 px progress bar eases toward real progress;
- on quit, everything fades out over 0.35 s.

| Theme dir | Plugin | Notes |
|---|---|---|
| `kiln/` | script | dark (default) |
| `kiln-light/` | script | light |
| `kiln-frames/` | two-step | dark frame-sequence fallback: `throbber-*.png` is the ember loop, `animation-*.png` is the end fade |
| `kiln-frames-light/` | two-step | light fallback |

In two-step the arrival animation cannot play at the start (that plugin plays
`animation-*` at the end), so the fallback shows the settled logo plus the loop.

**Reduced motion.** Plymouth exposes no accessibility setting. Set
`reduced_motion = 1;` at the top of `kiln.script`, or regenerate with
`--reduced-motion`. The arches then appear in place with no pulse, and the
progress bar still moves. The SMIL preview honours `prefers-reduced-motion`.

**Install (not done; for later, on the VM or an image):**

```sh
sudo apt install plymouth plymouth-themes          # script + two-step plugins
sudo cp -r packaging/kilnlinux/plymouth/kiln packaging/kilnlinux/plymouth/kiln-light \
           packaging/kilnlinux/plymouth/kiln-frames packaging/kilnlinux/plymouth/kiln-frames-light \
           /usr/share/plymouth/themes/
sudo plymouth-set-default-theme -R kiln            # or kiln-light / kiln-frames; -R rebuilds the initramfs
# kernel cmdline needs: quiet splash
# test without rebooting:  sudo plymouthd; sudo plymouth --show-splash; sleep 8; sudo plymouth quit
```

**Smooth handoff.** Have the display manager start with
`plymouth quit --retain-splash` (GDM and SDDM do this) and use the same
background colour as the greeter (`#1F1E1C` dark, `#FAF9F5` light).

**Verification status.** The frames, preview strips
(`preview/strip-{dark,light}.png`) and the SMIL file were rendered and viewed
on the Mac. **The Plymouth themes have NOT been run inside the VM.** Plymouth
is not installed there, and installing was out of scope. The script was
written against the documented Plymouth script API but has not been executed by
Plymouth. Expect possible small fixes on first real run, such as
`Image.Text` arguments and sprite opacity on some renderers.
